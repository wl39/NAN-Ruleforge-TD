# 카드 효과 공통 규칙

## 1. 단위

| 항목 | 내부 단위 | 문서 환산 |
| --- | --- | --- |
| 시간 | 30틱 = 1초 | 90틱 = 3초 |
| 체력·피해 | 1,000 milliHP = 표시 피해 1 | 500 milliHP = 0.5 피해 |
| 거리·반경 | 1,000 milli = 논리 거리 1 | 1,500 milli = 1.5칸 |
| 배율·확률 | 10,000 bps = 100% | 1,500 bps = 15%p |
| 골드·본진 체력 | 정수 | 그대로 표시 |

문서에서는 읽기 쉬운 값과 내부 값을 함께 쓴다. 피해 계산은 정수로 수행하고, 양수 원 피해가 최종 계산 후 1 milliHP보다 작으면 1 milliHP를 적용한다.

## 2. 실행 문맥

- 타워의 `SubjectType`이 탄환 또는 적 해석을 결정한다.
- 카드는 기본적으로 슬롯 왼쪽에서 오른쪽으로 실행한다.
- 생성된 개체는 자신을 만든 카드를 다시 실행하지 않고 다음 카드부터 이어서 실행한다.
- 원본 가지는 앞선 카드가 만든 상태와 바인딩을 유지한다. 새 가지는 카드가 명시적으로 상속시키는 것만 가진다.
- 카드 프로그램은 웨이브 시작 시 고정 복사한다. 전투 중 원본 JSON 변경은 현재 웨이브에 반영하지 않는다.
- 동일 거리 후보는 `EntityId` 오름차순으로 정렬해 결정성을 보장한다.

## 3. 피해와 상태이상

- 물리 피해는 `100 / (100 + 유효 방어력)`을 곱한다.
- 방어 무시는 방어력을 먼저 줄인 뒤 피해 감소식을 계산한다.
- 화염·독 피해는 해당 속성 저항을 적용한다. 중독은 방어력 50%를 무시하지만 독 저항은 무시하지 않는다.
- 표식·저주·범위 취약·단일 취약은 해당 조건의 피해에만 곱연산한다.
- 지속 피해의 한 틱 피해는 `기본 틱 피해 × 중첩 × 출처 배율`이다.
- 상태 갱신은 별도 설명이 없으면 같은 출처의 중첩을 올리고 지속시간을 최대값으로 갱신한다.
- 둔화 최종 감소 상한은 60%, 표식의 모든 출처 합산 받는 피해 증가 상한은 50%다.
- 기절·속박·에어본은 정예와 보스에게 완전 제어 대신 제어 저항 게이지 30을 준다. 게이지 100 도달 시 짧은 행동 방해 후 다음 임계치가 25 증가한다.

## 4. 보상과 가계

- 분열·복제·환생으로 개체 수가 늘어도 부모 가계의 골드와 웨이브 진행도 총량은 증가하지 않는다.
- 추가 보상이 없는 유령·환영은 골드와 웨이브 진행도 모두 0이다.
- `골드 획득`, `거대화`, `가속`의 적 보상 증가는 `(가계, 타워, 카드 인스턴스, 증가 종류)`마다 한 번만 적용한다.
- 카드로 생성된 골드는 같은 골드 카드 또는 경제 타워를 재발동시키지 않는다.

## 5. 연쇄 안전 한도

| 제한 | 값 |
| --- | ---: |
| RootChain 깊이 | 8 |
| RootChain 이벤트 | 256 |
| RootChain 탄환 생성 | 64 |
| 적 가계 누적 개체 비상 상한 | 256 |
| RootChain 카드 실행 | 32 |
| RootChain 재귀 | 1 |
| RootChain 신화 반복 | 3 |
| 한 틱 전체 이벤트 | 4,096 |
| 이벤트 큐 대기 | 16,384 |
| 탄환 관통 | 12 |
| 탄환 도탄 | 8 |
| 탄환 수명 | 450틱(15초) |

- 생성·폭발처럼 여러 결과를 만드는 효과는 필요한 이벤트 슬롯을 먼저 한 묶음으로 예약한다.
- 예약에 실패하면 일부 대상만 처리하지 않고 그 효과 전체를 취소한다.
- 같은 활성화에서 `첫 적중 또는 소멸`, `사망 시`, `부활` 같은 일회성 바인딩은 한 번만 소비한다.
- 반복 강도 감소는 매 반복마다 곱연산한다. 65% 반복이면 `100% → 65% → 42.25% → 27.46%`다.

## 6. 카드 레벨

이 문서의 수치는 레벨 I 기준이다. 레벨과 티어는 별개이며 최종 강화는 III-A 또는 III-B 중 하나만 선택한다. 강화는 `(CardId, Level, Branch)`로 표현하고 새 카드 ID를 만들지 않는다. 현재 Phase 1 런은 레벨 I만 활성화한다.
