# 5티어 신화 카드 효과

신화 카드는 런의 핵심 규칙을 바꾸는 대규모 생성·공유·반복 효과다. 기본 연산 비용 5, 현재 슬롯 비용 1이다. 모든 수치는 레벨 I 기준이다.

## 1. 특이점 (`singularity`)

- 태그: 흡수, 범위, 폭발
- 탄환: 120틱(4초) 동안 5틱마다 반경 2,400 milli의 아군 탄환을 남은 거리의 50%만큼 끌어당긴다. 접촉한 탄환을 최대 8발 흡수하고, 흡수할 때마다 그 탄환 피해의 65%를 자신의 피해에 더한다. 소멸 시 흡수한 각 탄환 피해의 65% 합계와 적중 바인딩을 반경 안 최대 8명에게 방출한다.
- 적: 120틱 동안 5틱마다 반경 2,500 milli의 주변 적을 남은 경로 거리의 25%만큼 끌어당기고 자신이 받은 실제 피해의 30%를 최대 8명에게 균등 전파한다. 원래 대상이 받는 피해는 줄지 않는다. 사망 시 반경 안 최대 8명에게 자신의 최대 체력 35% 피해를 준다.
- 제한: 흡수·공유된 피해는 다시 흡수·공유하지 않는다. 보상과 진행도는 증가하지 않으며 방출 전체는 원자적으로 예약한다.

## 2. 불사조 코어 (`phoenix_core`)

- 태그: 환생, 화염, 귀환
- 탄환: 소멸 후 피해 150%, 속도 125%, 크기·충돌 반경 100%의 강화 탄환으로 1회 부활한다. 부활 탄환의 최대 수명은 90틱(3초).
- 적: 사망 후 최대 체력의 30%로 1회 부활한다. 기존 상태이상은 제거하고 상태이상 종류당 받는 피해 +15% 취약으로 변환한다. 취약은 120틱(4초), 최대 3중첩.
- 제한: 부활 개체는 다시 부활하지 않는다. 적은 추가 보상·진행도를 주지 않으며 취약 총배율은 공통 취약 상한 200%를 넘지 않는다.

## 3. 시간 균열 (`time_rift`)

- 태그: 시간, 메아리, 생성
- 탄환: 6틱(0.2초) 전 위치의 과거 잔상과 6틱 뒤 예상 위치의 미래 잔상 각 1발, 총 2발을 만든다. 각 잔상 피해는 원본의 60%이며 위치 간격은 `탄환 속도 × 6틱`, 최대 750 milli다.
- 적: 120틱(4초) 전 위치와 120틱 뒤 예상 위치에 120틱 수명의 잔상 2개를 만든다. 각 잔상이 받은 실제 피해의 50%를 원본에게 전달하며 위치 간격은 최대 750 milli다.
- 제한: 출처당 시간 잔상 최대 6개. 잔상은 추가 보상·진행도 0이고 전달 피해를 다시 전달하지 않는다.

## 4. 거울 세계 (`mirror_world`)

- 태그: 거울, 복제, 생성
- 탄환: 타워 위치를 중심으로 현재 탄환의 점대칭 위치에 같은 카드 효과를 가진 거울 탄환 1발을 피해 100%로 생성한다. 점대칭 위치가 타워에서 2,500 milli보다 멀면 그 반경으로 제한한다.
- 적: 타워 위치를 중심으로 원본의 점대칭 위치에 환영 적 1기를 만들고 원본과 체력을 100% 공유한다. 환영 위치도 타워 반경 2,500 milli로 제한한다.
- 제한: 한 활성화당 1개. 거울 개체는 다시 거울을 만들지 않는다. 적 환영의 보상과 진행도는 0이며 공유 피해는 재공유하지 않는다.

## 5. 우로보로스 (`ouroboros`)

- 태그: 문법, 반복, 연쇄
- 탄환: 카드 순서가 끝나면 같은 탄환이 전체 프로그램을 위력 65%로 다시 실행한다. 전달될 때마다 기존 위력에 65%를 곱하며 최대 3회 반복한다.
- 적: 카드 순서가 끝나면 반경 3,000 milli의 아직 방문하지 않은 가장 가까운 적에게 전체 프로그램을 위력 65%로 전달한다. 전달마다 다시 65%로 감소하며 최대 3회.
- 예시: 최초 100%, 1회차 65%, 2회차 42.25%, 3회차 27.46%.
- 제한: 같은 RootChain에서 같은 대상을 두 번 방문하지 않는다. RootChain 깊이 8, 카드 실행 32, 이벤트 256, 신화 반복 3 상한을 모두 적용한다.
