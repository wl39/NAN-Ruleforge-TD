# 4티어 전설 카드 효과

전설 카드는 카드 프로그램의 방향, 해석, 반복과 상속 규칙을 바꾼다. 기본 연산 비용 4, 슬롯 비용 1이다. 모든 수치는 레벨 I 기준이다.

## 1. 재귀 (`recursion`)

- 태그: 문법, 반복
- 탄환: 마지막 카드 실행 후 첫 번째 탄환 해석 카드를 1회 더 실행한다.
- 적: 마지막 카드 실행 후 첫 번째 적 해석 카드를 1회 더 실행한다.
- 제한: 한 RootChain에서 재귀 1회. 재실행된 첫 카드가 재귀여도 추가 재귀를 만들지 않으며 카드 실행 32회 상한을 따른다.

## 2. 역순 실행 (`reverse_order`)

- 태그: 문법, 역방향
- 탄환: 해당 타워의 탄환 프로그램을 오른쪽에서 왼쪽으로 실행한다.
- 적: 해당 타워의 적 프로그램을 오른쪽에서 왼쪽으로 실행한다.
- 규칙: 프로그램 진입점과 다음 카드 커서만 반전한다. 각 카드 내부의 효과 노드 순서는 유지한다. 역순 카드 자체도 프로그램 항목으로 한 번 실행된다.

## 3. 이중 해석 (`dual_interpretation`)

- 태그: 문법, 이중
- 탄환: 바로 다음 카드의 탄환 효과를 현재 탄환에 100% 위력으로 실행하고, 그 카드의 적 효과를 다음 적중 대상에게 100% 위력으로 실행한다.
- 적: 바로 다음 카드의 적 효과를 현재 적에게 실행하고, 같은 카드의 탄환 효과를 가진 유령 탄환 1발을 생성한다.
- 제한: 한 활성화당 1회. 다음 카드가 없으면 아무 추가 효과도 만들지 않는다. 유령 탄환은 같은 이중 해석을 다시 발동하지 않는다.

## 4. 무한 궤도 (`infinite_orbit`)

- 태그: 궤도, 반복, 이동
- 탄환: 대상 주위를 반경 900 milli로 최대 150틱(5초) 공전한다. 10틱마다 피해 75%로 타격하며 최대 6회 적중할 때 소멸한다.
- 적: 현재 위치부터 길이 1,500 milli의 짧은 경로 구간을 최대 180틱(6초) 동안 왕복한다. 이 상태에서 4회 피격되면 즉시 궤도에서 풀려난다.
- 제한: 이름과 달리 실제 무한 반복은 없다. 탄환 수명 450틱, 카드 실행·이벤트 예산을 모두 적용한다.

## 5. 과잉 복제 (`overclone`)

- 태그: 복제, 생성, 상속
- 탄환: 분열·복제된 탄환이 생성 카드 이전의 효과 최대 2개를 위력 75%로 추가 상속한다.
- 적: 분열·복제된 적이 이전 상태이상과 사망 바인딩 최대 2개를 위력 75%로 상속한다.
- 제한: 과잉 복제 자체, 재귀, 우로보로스 같은 문법 플래그는 상속하지 않는다. 보상 원장과 생성 제한은 복제되지 않는다.

## 6. 금단의 거래 (`forbidden_deal`)

- 태그: 골드, 반복, 위험 보상
- 탄환: 적중 시 2골드를 소비해 카드 프로그램을 위력 100%로 1회 더 실행한다. 골드가 부족하면 비용을 빼지 않고 탄환이 소멸한다.
- 적: 180틱(6초) 동안 30틱(1초)마다 1골드를 최대 6회 생성한다. 매 틱 크기 105%, 최대 체력 105%, 이동 속도 105%를 누적 적용한다.
- 제한: 생성 골드는 경제 트리거를 재발동시키지 않는다. 최대 체력 증가 시 현재 체력 비율을 유지하며 보상 예산은 늘지 않는다.

## 7. 마지막 명령 (`last_command`)

- 태그: 사망, 역방향, 반복
- 탄환: 소멸 시 장착 프로그램을 역순, 위력 100%로 1회 더 실행한다. 대상 탐색 반경은 2,500 milli다.
- 적: 사망 시 반경 2,500 milli의 살아 있는 적 최대 8명에게 장착 프로그램을 역순, 위력 100%로 적용한다.
- 제한: 한 개체당 1회. 마지막 명령으로 생긴 파생 개체는 같은 활성화의 마지막 명령을 다시 소비하지 못한다. 대상 전체를 원자적으로 예약한다.

## 8. 운명 고정 (`fate_lock`)

- 태그: 결정성, 확률, 주기
- 탄환: 다음 확률형 효과 1회를 확정 발동시킨다. 위력은 100%이며 이후 같은 확률은 원래의 결정적 주기로 돌아간다.
- 적: 120틱(4초) 동안 다음 확률형 효과 1회를 확정 발동시키되 위력은 85%가 된다.
- 규칙: 난수 성공으로 바꾸는 것이 아니라 카드 인스턴스별 누적 주기 카운터를 사용한다. 한 활성화에서 1회 소비한다.

## 9. 과부하 (`overload`)

- 태그: 반복, 범위, 위험 보상
- 탄환: 모든 카드를 위력 100%로 즉시 1회 더 실행한 뒤, 반경 1,500 milli에 탄환 피해 70% 폭발을 만들고 소멸한다.
- 적: 모든 적 해석 카드를 위력 100%로 1회 더 실행한다. 이후 90틱(3초) 동안 이동 속도 125%, 상태이상 저항 +30%p를 얻는다. 반경 2,500 milli는 파생 범위 효과에 사용한다.
- 제한: 한 개체당 1회. 추가 실행에서 과부하를 다시 발동하지 않으며 반복 전체가 이벤트 예산을 예약하지 못하면 실행하지 않는다.
