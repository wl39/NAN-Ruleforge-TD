## 문서의 권위

- 실제 런타임 수치의 단일 원본은 `Assets/Game/Data/Logic/phase1-content.json`이다.
- 이 폴더는 사람이 읽는 상세 명세다. JSON 수치를 바꾸면 해당 티어 문서도 함께 바꾼다.
- 카드 의미, 이중 해석, 실행 순서, 보상 보존과 무한 연쇄 방지 규칙은 수치 튜닝만으로 변경하지 않는다.
- 수치 표기의 `%`는 배율 기준이다. 예를 들어 `피해 65%`는 기존 피해에 `0.65`를 곱한다.
